# Post formats — {{channel_name}}

One file per post type that works for this page, named after the `item_type` value (e.g. `tip.md`, `news.md`, `question.md`). `/new-channel` creates them, and the writer follows them.

Each format file describes:
- **Structure**: hook → body → call to action, and how many lines each part takes
- **Length**: target characters or words for the caption
- **Example**: one short example in the page's voice (fictional, no real facts)
- **Notes**: anything that worked or flopped (update after `/import-insights`)
